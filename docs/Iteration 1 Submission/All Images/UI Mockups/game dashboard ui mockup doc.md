# Game dashboard UI document

## Purpose

This document explains the design components of the game dashboard UI design.

## Left side bar

The left side bar on the UI screen contains a games button which will take you to the game dashboard. As well as a profile button that will take you to the current sessions profile. Then we have the settings, info, as well as exit buttons.

## Game dashboard

In the centre of the UI screen contains the two multiplayer games, clicking on a game will instantly put a player into the queue.

## Right side bar

The side bar on the right of the UI screen contains the current session players username at the top as well as the players friends list. Friends can be added through the friends button at the top.
