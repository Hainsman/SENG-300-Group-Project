# Profile Dashboard UI document

## Purpose

This document explains the design components of the profile dashboard UI design.

## Top section

The top sections contains two text boxes that display the player's id and their username

## Game stats

In the centre of the UI screen contains the two multiplayer game statistics for the player. This includes: Wins, Loses, and Draws

## Bottom Buttons

The bottom of the screen contains two buttons that when clicked on bring the player to the settings screen or the main menu screen.
