# Join matchmaking and start a session #

Description: From the dashboard, the player selects a game and queues for matchmaking. The matchmaking service finds a match and the session manager creates a session. The GUI is told to open the Join Game page.

```uml
@startuml
title Sequence - Queue -> Match Found -> Join Game Page

actor Player
participant "GUI (Dashboard)" as GUI
participant "PlatformCore" as Core
Database "DB" as DB

Player -> GUI : choose gameType\nclick Queue
GUI -> Core : joinQueue(playerId, gameType)

note left of Core
    In this step we check data such
    as the player's score, if they are
    currently banned from entering a
    match, etc.
end note

Core -> DB : check if player meets requirements to join the game
Core <-- DB : player DOES NOT meets requirements

Core --> GUI : return error

GUI -> GUI : display message to player
note left of Core
    The message should include the 
    reason as to why the player
    is not allowed to enter the game
end note
@enduml
```
