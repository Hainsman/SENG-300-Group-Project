@startuml
title 01 - Platform Core & Services (Rough design)

interface ClientUI <<interface>> {
  + display UI
  + update UI from updates
  + send (request)
  + receive (update)
}



class ClientCore <<service>> {
  + handle local requests
  + turn requests into a message to the server
  + act on an update from a server message
  + handle(request) : handleLocal, handleServer
  + handleLocal(request) : update
  + handleServer(request) : message 
  + sendMessage(message) : void
  + getUpdate(update) : send to UI
}
note right of ClientCore
The exact distribution of functions between the main program
and the listener thread will be determined when coding starts,
this distribution is not final.
end note
class ClientReceiver <<service>> {
  + listen for messages from the server
  + get the type of update and act on it
  
  + receiveMessage(message) : getUpdate
  + getUpdate(message) : update
  + sendUpdate(update) : void
}

class ServerCore <<service>> {
  + receive messages from any client and handle them
  + route user actions to the correct service
  + 'Main' lobby for users, global chat
  + store server information, handle new connections
  + receiveMessage (message) : content
  + routeContent(content) : void, send to other services
}

class NETWORK <<stub>> {
  + Messages are sent and received over the network by TCP.
  + For communicating between threads and different programs
  + on the same computer using actual networking is a fairly
  + good solution since it's just port numbers on the same IP.
}

class Chat <<service>> {
  + send chat messsages to all users on it's list
  + List<int> users  : user ID's 
  + List<int> user IP addresses
  + receiveContent(content) : sendMessage(content,users)
  + sendMessage(content,users) : send the chat message \n to everyone on the list
}

class Database <<stub>> {
  + returns login Boolean
  + scoreboard updating 
  + storeData(): void
  + retrieveData(): void
}

class GameLobby <<service>> {
  + Separate chat and UI style to the main lobby
  + display game info
  + receiveContent(content) : void
  + requestJoin() : join matchmaking
}

class matchmaking <<service>> {
  + put user in the queue
  + when a match is found, route the join query via gamelobby
  + then if they accept create a new Game instance
  + and move both players over
}

class Game <<service>> {
  + send and recieve turn updates
  + check the validity of moves
  + send updated game state to both players
  + local chat instance
  + allow user to return to lobby or quit
}

interface GameEngine <<interface>> {
  + Rules and Validation
  + validateMove(move) : Boolean
  + updateGame(move) : new game state, next turn value
}

ClientUI --> ClientCore
ClientCore ..> NETWORK
NETWORK ..> ClientReceiver
ClientReceiver --> ClientCore

NETWORK ..> ServerCore
ServerCore --> Database
ServerCore --> GameLobby
ServerCore --> Chat
Chat ..> NETWORK
GameLobby --> Chat
GameLobby --> matchmaking
GameLobby ..> NETWORK
matchmaking --> GameLobby
matchmaking --> Game
Game --> GameLobby
Game ..> NETWORK
Game --> GameEngine
GameEngine --> Game
