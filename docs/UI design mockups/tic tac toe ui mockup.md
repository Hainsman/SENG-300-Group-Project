# Tic Tac Toe in game UI document

## Purpose

This document explains the design components of the Tic Tac Toe UI design

## Side bar

The side bar on the left corner contains a forfeit, settings, game info, and exit buttons.

## Turn label

Above the tic tac toe game board there is a label that changes based on the game state. If it is the current users turn then it will display: "Your turn" otherwise it will display "Waiting for turn".

## Username label

The two username labels underneath the game board will contain the players usernames and the chip color that they are playing as.

## Move history

The right of the tic tac toe game board will contain the move history between the two players. The moves show the color of the chip as well as the coordinates of the board that it was placed in ex: (1,2).

## Elo panel

The left of the tic tac toe game board will contain the elo rating of the current game as well as the elo gain/loss amount depending on the outcome of the current game.

## Game board

The game board will be featured in the middle of the tic tac toe UI screen and will contain a 3x3 grid.
